# ⚛️ FormuLab — Интерактивный справочник-тренажер формул

Интерактивная образовательная веб-платформа по **физике** и **математике** (включая материалы для подготовки к **ЕНТ, ЕГЭ и ОГЭ**). Позволяет изучать формулы через динамические симуляции, интерактивные графики и генератор практических задач с пошаговым разбором решений.

---

## ✨ Основные возможности

- 📚 **Каталог формул:** структурирован по темам (Механика, Термодинамика, Электродинамика, Алгебра, Геометрия).
- 🎛️ **Интерактивная лаборатория (FormulaLab):** изменяйте переменные через ползунки и наблюдайте за графиками и расчетами в реальном времени.
- ⚡ **Генератор задач на 1 клик:** мгновенная генерация уникальных практических задач с автоматической проверкой ответа.
- 📝 **Пошаговый разбор (KaTeX):** подробное пошаговое объяснение решений со всеми математическими выкладками.
- 🔥 **Трекинг успеваемости:** учет решенных задач, серия правильных ответов (streak) и процент точности.
- 🌓 **Темная и светлая темы:** современный адаптивный дизайн с поддержкой тем.

---

## 🛠️ Стек технологий

- **Frontend:** Vanilla JavaScript (ES Modules), HTML5, CSS3 (Glassmorphism & CSS Variables)
- **Math & Plots:** [KaTeX](https://katex.org/) (рендеринг LaTeX-формул), [Chart.js](https://www.chartjs.org/) (динамические графики)
- **Backend:** [FastAPI](https://fastapi.tiangolo.com/), [SymPy](https://www.sympy.org/) (символьные вычисления и генерация задач)
- **Server:** [Uvicorn](https://www.uvicorn.org/)

## 🚀 Запуск проекта локально

### 1. Установка зависимостей бэкенда
```bash
cd backend
pip install -r requirements.txt
cd ..
```

### 2. Запуск сервера
```bash
python backend/app.py
```
или:
```bash
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000
```

После запуска приложение доступно по адресу:
- 🌐 **Веб-интерфейс:** [http://localhost:8000](http://localhost:8000)
- 📖 **Swagger API документация:** [http://localhost:8000/docs](http://localhost:8000/docs)
